НМТ-2027 • Математика

Системний розбір за матеріалами НМТ-2025, НМТ-2026 та тренувальних баз 2027 року

Охоплює повну програму: теорію, розбір задокументованих типових та складних завдань, самостійну перевірку з відповідями.

1 Джерела та методика аналізу

Офіційна програма НМТ охоплює 6 великих блоків: числа і вирази; рівняння, нерівності та системи; функції; комбінаторика, ймовірність і статистика; планіметрія; стереометрія.

Структура тесту складається з 22 завдань (15 з вибором однієї відповіді, 3 на встановлення відповідності, 4 з короткою відповіддю). Максимальний бал — 32.

3 Числа, дроби, відсотки та пропорції

  • ОБОВ'ЯЗКОВО$a\% = \frac{a}{100}$
  • Збільшення числа $A$ на $p\%$: $A_{\text{нове}} = A \cdot \left(1 + \frac{p}{100}\right)$
  • Зменшення числа $A$ на $p\%$: $A_{\text{нове}} = A \cdot \left(1 - \frac{p}{100}\right)$
  • Послідовні зміни відсотків перемножуються: зміна на $+20\%$, а потім на $-20\%$ дає коефіцієнт $1.2 \cdot 0.8 = 0.96$ (зменшення на $4\%$).
  • Основна властивість пропорції: якщо $\frac{a}{b} = \frac{c}{d}$, то $a \cdot d = b \cdot c$ ($b, d \neq 0$).
Приклад у стилі НМТ (Складний)

Ціну товару спочатку підвищили на $25\%$, а потім нову ціну знизили на $20\%$. Як змінилася початкова ціна товару?

Розв'язання: Нехай початкова ціна $x$. Після підвищення: $1.25x$. Після зниження: $1.25x \cdot 0.80 = 1.00x$.
Відповідь: Ціна не змінилася ($100\%$ від початкової).
Завдання для самоперевірки

Завдання 1: Товар коштував $500$ грн. Його ціну підвищили на $12\%$. Яка нова ціна?

Відповідь: $560$ грн.

Завдання 2: Після знижки на $20\%$ ціна стала $640$ грн. Якою була початкова ціна?

Відповідь: $800$ грн.

4 Степені та корені

  • ОБОВ'ЯЗКОВО$a^m \cdot a^n = a^{m+n}$, $\frac{a^m}{a^n} = a^{m-n}$, $(a^m)^n = a^{m \cdot n}$
  • $a^{-n} = \frac{1}{a^n}$ ($a \neq 0$), $a^{\frac{m}{n}} = \sqrt[n]{a^m}$ ($a \ge 0$)
  • ВАЖЛИВО$\sqrt{a^2} = |a|$, а не просто $a$.
  • $\sqrt[n]{a \cdot b} = \sqrt[n]{a} \cdot \sqrt[n]{b}$ (для $a, b \ge 0$ при парному $n$).
Приклад у стилі НМТ

Спростіть вираз: $\frac{\sqrt{50}}{\sqrt{2}} + 27^{\frac{2}{3}}$.

Розв'язання: $\frac{\sqrt{50}}{\sqrt{2}} = \sqrt{\frac{50}{2}} = \sqrt{25} = 5$.
$27^{\frac{2}{3}} = (\sqrt[3]{27})^2 = 3^2 = 9$. Сума: $5 + 9 = 14$.
Відповідь: $14$.
Завдання для самоперевірки

Завдання 1: Обчисліть $2^{-3} \cdot 16^{\frac{3}{4}}$.

Відповідь: $\frac{1}{8} \cdot 8 = 1$.

Завдання 2: Спростіть $\sqrt{(x-5)^2}$ при $x < 5$.

Відповідь: $|x-5| = 5-x$.

5 Модуль дійсного числа

$$|x| = \begin{cases} x, & \text{якщо } x \ge 0 \\ -x, & \text{якщо } x < 0 \end{cases}$$
  • $|x| = a \implies x = \pm a \quad (\text{при } a \ge 0)$.
  • $|x| < a \iff -a < x < a \quad (\text{при } a > 0)$.
  • $|x| > a \iff x < -a \text{ або } x > a \quad (\text{при } a > 0)$.
  • Геометричний зміст: $|x - a|$ — це відстань між точками $x$ та $a$ на числовій осі.
Приклад у стилі НМТ

Знайдіть суму коренів рівняння $|2x - 3| = 7$.

Розв'язання: $2x - 3 = 7 \implies 2x = 10 \implies x_1 = 5$.
$2x - 3 = -7 \implies 2x = -4 \implies x_2 = -2$. Сума: $5 + (-2) = 3$.
Відповідь: $3$.
Завдання для самоперевірки

Завдання 1: Знайдіть кількість цілих розв'язків нерівності $|x - 2| \le 3$.

Відповідь: $-1 \le x \le 5 \implies$ цілі: $-1, 0, 1, 2, 3, 4, 5$ (усього 7).

6 Тотожні перетворення та многочлени

  • $(a \pm b)^2 = a^2 \pm 2ab + b^2$
  • $a^2 - b^2 = (a - b)(a + b)$
  • $a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$
  • Розклад квадратного тричлена: $ax^2 + bx + c = a(x - x_1)(x - x_2)$
Приклад у стилі НМТ

Скоротіть дріб: $\frac{x^2 - 6x + 9}{x^2 - 9}$.

Розв'язання: Чисельник: $(x-3)^2$. Знаменник: $(x-3)(x+3)$.
При $x \neq 3, x \neq -3$: $\frac{(x-3)^2}{(x-3)(x+3)} = \frac{x-3}{x+3}$.
Відповідь: $\frac{x-3}{x+3}$.
Завдання для самоперевірки

Завдання 1: Спростіть вираз $\frac{a^3 - 8}{a - 2} - a^2$.

Відповідь: $\frac{(a-2)(a^2+2a+4)}{a-2} - a^2 = a^2+2a+4 - a^2 = 2a+4$.

7 Рівняння: лінійні та квадратні

  • Квадратне рівняння $ax^2 + bx + c = 0$: $D = b^2 - 4ac$.
  • Якщо $D > 0 \implies x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$; якщо $D = 0 \implies x = -\frac{b}{2a}$; якщо $D < 0$ — дійсних коренів немає.
  • Теорема Вієта Для $x^2 + px + q = 0$: $x_1 + x_2 = -p$, $x_1 \cdot x_2 = q$.
Приклад у стилі НМТ

При якому значенні $a$ один із коренів рівняння $x^2 - 8x + a = 0$ на $2$ більший за інший?

Розв'язання: Нехай корені $x_1$ та $x_1 + 2$. За теоремою Вієта: $x_1 + (x_1 + 2) = 8 \implies 2x_1 = 6 \implies x_1 = 3$.
Тоді другий корінь $x_2 = 5$. За теоремою Вієта $a = x_1 \cdot x_2 = 3 \cdot 5 = 15$.
Відповідь: $a = 15$.
Завдання для самоперевірки

Завдання 1: Розв'яжіть рівняння $2x^2 - 5x + 2 = 0$. У відповідь запишіть більший корінь.

Відповідь: $x_1 = 2$, $x_2 = 0.5$. Більший корінь: $2$.

8 Нерівності та метод інтервалів

  • При множенні/діленні нерівності на від'ємне число знак нерівності змінюється на протилежний.
  • Алгоритм методу інтервалів:
    1. Перенести все в одну сторону, щоб справа був $0$.
    2. Знайти нулі чисельника та знаменника (ОДЗ: знаменник $\neq 0$).
    3. Нанести точки на числову вісь (строгі — виколоті, нестрогі чисельника — зафарбовані).
    4. Визначити знаки на проміжках та записати відповідь.
Приклад у стилі НМТ

Розв'яжіть нерівність $\frac{(x-3)(x+1)}{x-5} \le 0$.

Розв'язання: Нулі чисельника: $x = 3, x = -1$ (зафарбовані). Нуль знаменника: $x = 5$ (виколота).
Знаки на інтервалах $(-\infty; -1] \cup [3; 5)$: $-, +, -, +$.
Обираємо від'ємні проміжки: $x \in (-\infty; -1] \cup [3; 5)$.
Відповідь: $(-\infty; -1] \cup [3; 5)$.
Завдання для самоперевірки

Завдання 1: Знайдіть найменший цілий розв'язок нерівності $\frac{x+2}{x-4} < 0$.

Відповідь: $x \in (-2; 4) \implies$ найменше ціле $x = -1$.

9 Дробово-раціональні та ірраціональні рівняння

  • Рівняння $\sqrt{f(x)} = g(x)$ рівносильне системі:
    $$\begin{cases} f(x) = (g(x))^2 \\ g(x) \ge 0 \end{cases}$$
  • Завжди перевіряйте ОДЗ або виконуйте пряму перевірку знайдених коренів!
Приклад у стилі НМТ

Розв'яжіть рівняння $\sqrt{x + 3} = x - 3$.

Розв'язання: Умова: $x - 3 \ge 0 \implies x \ge 3$.
Підносимо до квадрата: $x + 3 = (x - 3)^2 \implies x + 3 = x^2 - 6x + 9 \implies x^2 - 7x + 6 = 0$.
Корені: $x_1 = 1, x_2 = 6$. Перевірка умовою $x \ge 3$: корінь $x = 1$ — сторонній.
Відповідь: $6$.
Завдання для самоперевірки

Завдання 1: Розв'яжіть рівняння $\sqrt{2x + 5} = 5 - x$.

Відповідь: $2x + 5 = 25 - 10x + x^2 \implies x^2 - 12x + 20 = 0 \implies x_1 = 2, x_2 = 10$. Перевірка: $x = 10$ дає $\sqrt{25} = -5$ (не підходить). Корінь: $x = 2$.

10 Показникові та логарифмічні вирази і рівняння

  • Логарифм: $\log_a b = c \iff a^c = b$ ($b > 0, a > 0, a \neq 1$).
  • $\log_a(x \cdot y) = \log_a x + \log_a y$
  • $\log_a\left(\frac{x}{y}\right) = \log_a x - \log_a y$
  • $\log_a (x^k) = k \cdot \log_a x$
  • Формула переходу: $\log_a b = \frac{\log_c b}{\log_c a}$
Приклад у стилі НМТ

Обчисліть значення виразу $\log_2 12 - \log_2 3 + 5^{\log_5 4}$.

Розв'язання: $\log_2 12 - \log_2 3 = \log_2\left(\frac{12}{3}\right) = \log_2 4 = 2$.
За основною логарифмічною тотожністю: $5^{\log_5 4} = 4$.
Сума: $2 + 4 = 6$.
Відповідь: $6$.
Завдання для самоперевірки

Завдання 1: Розв'яжіть рівняння $\log_3 (x^2 - 7) = 2$.

Відповідь: $x^2 - 7 = 3^2 = 9 \implies x^2 = 16 \implies x = \pm 4$. (ОДЗ перевищується, обидва підходять).

11 Функції, їх властивості та графіки

  • Парність: $f(-x) = f(x)$ — симетрична відносно осі $Oy$.
  • Непарність: $f(-x) = -f(x)$ — симетрична відносно початку координат $(0,0)$.
  • Вершина параболи $y = ax^2 + bx + c$: $x_v = -\frac{b}{2a}$, $y_v = f(x_v)$.
  • Перетворення графіків: $y = f(x - a)$ — зсув вправо на $a$; $y = f(x) + b$ — зсув вгору на $b$.
Приклад у стилі НМТ

Знайдіть ординату вершини параболи $y = 2x^2 - 8x + 5$.

Розв'язання: $x_v = -\frac{-8}{2 \cdot 2} = \frac{8}{4} = 2$.
$y_v = 2(2)^2 - 8(2) + 5 = 8 - 16 + 5 = -3$.
Відповідь: $-3$.
Завдання для самоперевірки

Завдання 1: Знайдіть область визначення функції $y = \frac{1}{\sqrt{4 - x^2}}$.

Відповідь: $4 - x^2 > 0 \implies x \in (-2; 2)$.

12 Похідна, її геометричний зміст та дослідження функцій

  • Правила: $(x^n)' = n \cdot x^{n-1}$, $(e^x)' = e^x$, $(\ln x)' = \frac{1}{x}$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$.
  • Геометричний зміст: $k = \tan \alpha = f'(x_0)$ — кутовий коефіцієнт дотичної.
  • Рівняння дотичної: $y = f(x_0) + f'(x_0)(x - x_0)$.
  • Якщо $f'(x) > 0$ на проміжку $\implies$ функція зростає; якщо $f'(x) < 0 \implies$ спадає.
Приклад у стилі НМТ

Знайдіть точку екстремуму (мінімуму) функції $f(x) = \frac{1}{3}x^3 - 4x + 1$.

Розв'язання: Похідна $f'(x) = x^2 - 4$. Критичні точки: $x^2 - 4 = 0 \implies x = \pm 2$.
При переході через точку $x = 2$ похідна змінює знак з $-$ на $+$ (мінімум).
Відповідь: $x = 2$.
Завдання для самоперевірки

Завдання 1: Знайдіть кутовий коефіцієнт дотичної до графіка функції $f(x) = x^2 - 3x$ у точці $x_0 = 4$.

Відповідь: $f'(x) = 2x - 3 \implies k = f'(4) = 2(4) - 3 = 5$.

13 Первісна та визначений інтеграл

  • $\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$
  • Формула Ньютона-Лейбніца: $\int_{a}^{b} f(x) dx = F(b) - F(a)$
  • Площа криволінійної трапеції: $S = \int_{a}^{b} f(x) dx$.
Приклад у стилі НМТ

Обчисліть площу фігури, обмеженої лініями $y = 3x^2$, $y = 0$, $x = 1$, $x = 2$.

Розв'язання: $S = \int_{1}^{2} 3x^2 dx = \left[ x^3 \right]_{1}^{2} = 2^3 - 1^3 = 8 - 1 = 7$.
Відповідь: $7$.
Завдання для самоперевірки

Завдання 1: Знайдіть первісну $F(x)$ для $f(x) = 4x + 1$, якщо її графік проходить через точку $(1; 5)$.

Відповідь: $F(x) = 2x^2 + x + C$. Підставляємо $(1;5): 2(1)^2 + 1 + C = 5 \implies C = 2 \implies F(x) = 2x^2 + x + 2$.

14 Комбінаторика

  • Перестановки: $P_n = n!$ (порядок важливий, задіяні всі елементи).
  • Розміщення: $A_n^k = \frac{n!}{(n-k)!}$ (порядок важливий, обираємо $k$ з $n$).
  • Сполучення (комбінації): $C_n^k = \frac{n!}{k!(n-k)!}$ (порядок не важливий).
Приклад у стилі НМТ

У класі $10$ хлопців та $12$ дівчат. Скількома способами можна обрати команду з $2$ хлопців та $1$ дівчини?

Розв'язання: Способи обрати хлопців: $C_{10}^2 = \frac{10 \cdot 9}{2} = 45$.
Способи обрати дівчину: $C_{12}^1 = 12$.
За правилом добутку: $45 \cdot 12 = 540$.
Відповідь: $540$.
Завдання для самоперевірки

Завдання 1: Скільки існують різних чотиризначних чисел, усі цифри яких різні, складених із цифр $1, 2, 3, 4, 5$?

Відповідь: $A_5^4 = \frac{5!}{(5-4)!} = 120$.

15 Теорія ймовірностей

  • Класична ймовірність: $P(A) = \frac{m}{n}$, де $m$ — кількість сприятливих подій, $n$ — загальна кількість усіх рівноможливих подій.
  • Протилежна подія: $P(\bar{A}) = 1 - P(A)$.
  • Сума несумісних подій: $P(A \cup B) = P(A) + P(B)$.
Приклад у стилі НМТ

У коробці лежать $6$ зелених і $4$ червоні кулі. Яка ймовірність того, що дві навмання витягнуті кулі виявляться зеленими?

Розв'язання: Загальна кількість способів витягти $2$ кулі з $10$: $n = C_{10}^2 = \frac{10 \cdot 9}{2} = 45$.
Сприятливі способи (витягти $2$ зелені з $6$): $m = C_6^2 = \frac{6 \cdot 5}{2} = 15$.
Ймовірність: $P = \frac{15}{45} = \frac{1}{3} \approx 0.33$.
Відповідь: $\frac{1}{3}$.
Завдання для самоперевірки

Завдання 1: Гральний кубик кидають двічі. Яка ймовірність того, що сума очок дорівнюватиме $5$?

Відповідь: Варіанти $(1,4), (2,3), (3,2), (4,1) \implies m = 4$. Усього $n = 36$. $P = \frac{4}{36} = \frac{1}{9}$.

16 Елементи математичної статистики

  • Середнє арифметичне: сума всіх значень, поділена на їх кількість.
  • Мода ($Mo$): значення, яке зустрічається найчастіше.
  • Медіана ($Me$): серединне значення впорядкованого ряду.
  • Розмах вибірки ($R$): різниця між найбільшим і найменшим значенням ($R = x_{\max} - x_{\min}$).
Приклад у стилі НМТ

Дано вибірку: $3, 7, 2, 7, 10, 13$. Знайдіть медіану цієї вибірки.

Розв'язання: Впорядкуємо ряд: $2, 3, 7, 7, 10, 13$.
Кількість елементів парна ($6$). Медіана дорівнює середньому арифметичному двох центральних елементів ($7$ та $7$): $Me = \frac{7+7}{2} = 7$.
Відповідь: $7$.
Завдання для самоперевірки

Завдання 1: Для ряду чисел $4, 8, 12, 16, 20$ знайдіть середнє арифметичне та розмах.

Відповідь: Середнє: $\frac{60}{5} = 12$. Розмах: $20 - 4 = 16$.

17 Координати та вектори

  • Модуль вектора $\vec{a}(x; y)$: $|\vec{a}| = \sqrt{x^2 + y^2}$.
  • Скалярний добуток: $\vec{a} \cdot \vec{b} = x_1 x_2 + y_1 y_2 = |\vec{a}| \cdot |\vec{b}| \cos \varphi$.
  • Умова перпендикулярності: $\vec{a} \cdot \vec{b} = 0$.
  • Умова колінеарності: $\frac{x_1}{x_2} = \frac{y_1}{y_2}$.
Приклад у стилі НМТ

При якому значенні $m$ вектори $\vec{a}(m; 4)$ та $\vec{b}(3; -2)$ перпендикулярні?

Розв'язання: Умова перпендикулярності: $\vec{a} \cdot \vec{b} = 0 \implies m \cdot 3 + 4 \cdot (-2) = 0$.
$3m - 8 = 0 \implies 3m = 8 \implies m = \frac{8}{3}$.
Відповідь: $\frac{8}{3}$.
Завдання для самоперевірки

Завдання 1: Знайдіть довжину вектора $\vec{c} = 2\vec{a} - \vec{b}$, якщо $\vec{a}(1; 2)$, $\vec{b}(-1; 1)$.

Відповідь: $\vec{c} = (2 \cdot 1 - (-1); 2 \cdot 2 - 1) = (3; 3)$. Довжина: $|\vec{c}| = \sqrt{3^2 + 3^2} = \sqrt{18} = 3\sqrt{2}$.

18 Трикутники

  • Площа: $S = \frac{1}{2} a h_a = \frac{1}{2} a b \sin C = \sqrt{p(p-a)(p-b)(p-c)}$ (Формула Герона).
  • Теорема Піфагора: $c^2 = a^2 + b^2$.
  • Теорема синусів: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$.
  • Теорема косинусів: $c^2 = a^2 + b^2 - 2ab \cos C$.
Приклад у стилі НМТ

У трикутнику Сторони дорівнюють $5$ см і $8$ см, а кут між ними $60^\circ$. Знайдіть третю сторону.

Розв'язання: За теоремою косинусів: $c^2 = 5^2 + 8^2 - 2 \cdot 5 \cdot 8 \cdot \cos 60^\circ$.
$c^2 = 25 + 64 - 80 \cdot 0.5 = 89 - 40 = 49 \implies c = 7$ см.
Відповідь: $7$ см.
Завдання для самоперевірки

Завдання 1: Знайдіть радіус кола, описаного навколо трикутника зі стороною $6\sqrt{3}$ см, яка лежить проти кута $60^\circ$.

Відповідь: За теоремою синусів $2R = \frac{a}{\sin A} = \frac{6\sqrt{3}}{\sin 60^\circ} = \frac{6\sqrt{3}}{\frac{\sqrt{3}}{2}} = 12 \implies R = 6$ см.

19 Чотирикутники

  • Паралелограм: $S = a \cdot h_a = a b \sin \alpha$. Діагоналі точкою перетину діляться навпіл.
  • Ромб: $S = \frac{d_1 d_2}{2}$. Діагоналі перпендикулярні і є бісектрисами.
  • Трапеція: $S = \frac{a + b}{2} \cdot h = m \cdot h$ ($m$ — середня лінія).
Приклад у стилі НМТ

Діагоналі ромба дорівнюють $12$ см та $16$ см. Знайдіть сторону ромба та його периметр.

Розв'язання: Діагоналі ромба перпендикулярні й діляться навпіл $\implies$ утворюють прямокутний трикутник із катетами $6$ см і $8$ см.
Гіпотенуза (сторона ромба): $a = \sqrt{6^2 + 8^2} = \sqrt{100} = 10$ см.
Периметр: $P = 4a = 40$ см.
Відповідь: Сторона $10$ см, периметр $40$ см.
Завдання для самоперевірки

Завдання 1: Основи рівнобічної трапеції дорівнюють $6$ см і $14$ см, а бічна сторона — $5$ см. Знайдіть площу трапеції.

Відповідь: Проекція бічної сторони на основу: $\frac{14 - 6}{2} = 4$ см. Висота $h = \sqrt{5^2 - 4^2} = 3$ см. Площа $S = \frac{6 + 14}{2} \cdot 3 = 30\text{ см}^2$.

20 Коло та круг

  • Довжина кола: $C = 2\pi R$. Площа круга: $S = \pi R^2$.
  • Вписаний кут дорівнює половині центрального кута, що спирається на ту саму дугу.
  • Вписаний кут, що спирається на діаметр, дорівнює $90^\circ$.
  • Властивість дотичних: відрізки дотичних, проведених з однієї точки до кола, рівні.
Приклад у стилі НМТ

Центральний кут на $40^\circ$ більший за вписаний кут, що спирається на ту саму дугу. Знайдіть градусну міру вписаного кута.

Розв'язання: Нехай вписаний кут $x$, тоді центральний кут $2x$.
За умовою: $2x - x = 40^\circ \implies x = 40^\circ$.
Відповідь: $40^\circ$.
Завдання для самоперевірки

Завдання 1: Знайдіть площу сектора круга радіуса $6$ см, якщо відповідний центральний кут дорівнює $60^\circ$.

Відповідь: $S_{\text{сект}} = \frac{\pi R^2 \cdot \alpha}{360^\circ} = \frac{\pi \cdot 36 \cdot 60}{360} = 6\pi\text{ см}^2$.

21 Подібність фігур та масштаб

  • Коефіцієнт подібності: $k = \frac{a_1}{a_2}$.
  • Відношення периметрів: $\frac{P_1}{P_2} = k$.
  • Відношення площ: $\frac{S_1}{S_2} = k^2$.
  • Відношення об'ємів подібних тіл: $\frac{V_1}{V_2} = k^3$.
Приклад у стилі НМТ

Площі двох подібних трикутників дорівнюють $18\text{ см}^2$ та $50\text{ см}^2$. Знайдіть периметр більшого трикутника, якщо периметр меншого дорівнює $24$ см.

Розв'язання: $k^2 = \frac{50}{18} = \frac{25}{9} \implies k = \sqrt{\frac{25}{9}} = \frac{5}{3}$.
$\frac{P_2}{P_1} = k \implies P_2 = 24 \cdot \frac{5}{3} = 40$ см.
Відповідь: $40$ см.
Завдання для самоперевірки

Завдання 1: Сторона першого куба у $3$ рази більша за сторону другого. У скільки разів об'єм першого куба більший за об'єм другого?

Відповідь: $k = 3 \implies \frac{V_1}{V_2} = k^3 = 3^3 = 27$ разів.

22 Стереометрія: призма та паралелепіпед

  • Об'єм призми: $V = S_{\text{осн}} \cdot h$.
  • Об'єм прямокутного паралелепіпеда: $V = a \cdot b \cdot c$.
  • Діагональ прямокутного паралелепіпеда: $d = \sqrt{a^2 + b^2 + c^2}$.
Приклад у стилі НМТ

Основою прямої призми є прямокутний трикутник із катетами $6$ см і $8$ см. Знайдіть об'єм призми, якщо її бічне ребло дорівнює $10$ см.

Розв'язання: $S_{\text{осн}} = \frac{1}{2} \cdot 6 \cdot 8 = 24\text{ см}^2$.
$V = S_{\text{осн}} \cdot h = 24 \cdot 10 = 240\text{ см}^3$.
Відповідь: $240\text{ см}^3$.
Завдання для самоперевірки

Завдання 1: Знайдіть діагональ куба, площа поверхні якого дорівнює $54\text{ см}^2$.

Відповідь: $S = 6a^2 = 54 \implies a^2 = 9 \implies a = 3$ см. Діагональ $d = a\sqrt{3} = 3\sqrt{3}$ см.

23 Піраміда, циліндр, конус, куля

Тіло Об'єм ($V$) Площа поверхні ($S$)
Піраміда $V = \frac{1}{3} S_{\text{осн}} h$ $S_{\text{повн}} = S_{\text{осн}} + S_{\text{біч}}$
Циліндр $V = \pi R^2 h$ $S_{\text{біч}} = 2\pi Rh$, $S_{\text{повн}} = 2\pi R(R+h)$
Конус $V = \frac{1}{3} \pi R^2 h$ $S_{\text{біч}} = \pi R L$, $S_{\text{повн}} = \pi R(R+L)$
Куля / Сфера $V = \frac{4}{3} \pi R^3$ $S = 4\pi R^2$
Приклад у стилі НМТ

Осьовим перерізом конуса є рівносторонній трикутник зі стороною $8$ см. Знайдіть об'єм конуса.

Розв'язання: Радіус основи $R = 4$ см, твірна $L = 8$ см.
Висота $h = \sqrt{L^2 - R^2} = \sqrt{64 - 16} = \sqrt{48} = 4\sqrt{3}$ см.
Об'єм: $V = \frac{1}{3} \pi (4)^2 (4\sqrt{3}) = \frac{64\sqrt{3}\pi}{3}\text{ см}^3$.
Відповідь: $\frac{64\sqrt{3}\pi}{3}\text{ см}^3$.
Завдання для самоперевірки

Завдання 1: Знайдіть площу сфери, якщо об'єм відповідної кулі дорівнює $36\pi\text{ см}^3$.

Відповідь: $V = \frac{4}{3}\pi R^3 = 36\pi \implies R^3 = 27 \implies R = 3$ см. Площа $S = 4\pi R^2 = 4\pi (9) = 36\pi\text{ см}^2$.

24 Типові «зв'язки» між темами

  • Парабола + Похідна: абсцису вершини можна знайти з умови $f'(x) = 0$.
  • Геометрія + Квадратні рівняння: задачі на площу часто приводять до квадратного рівняння.
  • Логарифми + ОДЗ: розв'язання рівнянь обов'язково починається з аналізу системи умов на аргумент та основу.
  • Стереометрія + Прямокутний трикутник: кут між похилою та площиною розглядається через прямокутний трикутник, утворений висотою, похилою та її проекцією.

25 НМТ-пастки, які треба контролювати

  • ПАСТКА 1 Пам'ятайте, що $\sqrt{x^2} = |x|$. Не втрачайте знак при $x < 0$!
  • ПАСТКА 2 При діленні нерівності на від'ємне число не забувайте змінювати знак нерівності на протилежний.
  • ПАСТКА 3 Не включення виколотих точок ОДЗ (знаменники, підкореневі вирази, аргументи логарифмів).
  • ПАСТКА 4 Послідовні відсотки: збільшення на $20\%$, а потім зменшення на $20\%$ НЕ повертає початкове число!
  • ПАСТКА 5 У геометрії площі подібних фігур відносяться як $k^2$, а не як $k$!
